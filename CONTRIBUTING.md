# Contributing to ActiRust

Thank you for your interest in contributing to **ActiRust**! We welcome contributions from everyone, whether it's reporting a bug, improving documentation, or adding new features.

## How to Contribute

### Reporting Bugs
If you find a bug, please check the [Issues](https://github.com/yevhenivashchenko/ActiRust/issues) page to see if it has already been reported. If not, please open a new issue with:
* A clear and descriptive title.
* Steps to reproduce the issue.
* Information about your operating system (Windows, Linux, or macOS).
* Any relevant logs or error messages.

### Suggesting Features
We love new ideas! If you have a feature request or an idea for improvement, feel free to open an issue and tag it as an "enhancement."

### Pull Requests
1. **Fork** the repository.
2. **Create a branch** for your feature or fix (`git checkout -b feature/amazing-feature`).
3. **Make your changes** and ensure the code follows Rust best practices.
4. **Test your code** to ensure everything works as expected.
5. **Commit your changes** with descriptive messages.
6. **Push to your fork** and submit a **Pull Request** to the `main` branch.

## Development Setup

Since ActiRust is built with **Rust**, ensure you have [Rust installed](https://www.rust-lang.org/tools/install).
