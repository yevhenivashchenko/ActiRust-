# ActiRust-
**ActiRust** is a simple, lightweight, and blazing-fast open-source tool written in Rust for tracking and detecting user and system activity.

The project is designed to monitor events (keystrokes, mouse movements, process activity) with minimal system resource consumption.

---

## ✨ Features

* **High Performance:** Powered by Rust, it runs incredibly fast without draining your CPU.
* **Cross-Platform:** Planned support for Windows, Linux, and macOS.
* **Low Memory Footprint:** Zero heavy dependencies or bulky runtimes.
* **Customizable:** Easily configure triggers for specific types of activity.

## 🚀 Roadmap

- [ ] Mouse and keyboard activity detection (Idle/Active tracking)..
- [ ] Active window and background process monitoring.
- [ ] Real-time event logging.
- [ ] Notifications when specific activity thresholds are met.
